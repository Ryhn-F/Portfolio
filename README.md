# Ray's Professional Portfolio 🚀

A dynamic personal portfolio built with modern web technologies, showcasing my journey as a Fullstack Developer and National Web Design Champion.

## 🛠 Tech Stack
- **Frontend:** React.js, SCSS (Sass), Framer Motion
- **Backend:** Sanity.io (Headless CMS)
- **Hosting:** Vercel / Netlify

## 🏆 Key Features
- Dynamic content management via Sanity Studio
- Responsive layout for Mobile & Desktop
- Showcase of BNSP Certified Projects & OTN Awards

## 📦 How to Run
1. Clone repository
2. `npm install`
3. `npm start`
